# Demo asset license and provenance

The thirteen `event-*.png` and `venue-*.png` files are original, fictional
vector-style illustrations created for AttendTa with `generate.py`. They do not
represent photographs or depictions of the named venues. No online images are
used in these banners. The generated PNGs are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); no attribution is
required. The generator uses Pillow and a locally installed Arial font; see their
respective licenses if redistributing those tools or the font. The bundled PNGs
contain rasterized text, not a font file.

Run `python database/demo-assets/generate.py` with Pillow and Arial installed to
recreate the banners. `event.png` and `venue.png` are unused legacy project
illustrations and are not part of the demo package.

## How to read this map

- **Automated coverage** names an existing xUnit test as `Class.Method`, or `none`. Only the two
  existing test projects are used: `tests/ASI.Basecode.Services.Tests` and
  `tests/ASI.Basecode.IntegrationTests`.
- **Manual case / steps or deferred** either names a concrete 8.6 case from
  `finale-test-cases.md`, or records `deferred (8.13 — <register row> / <ticket>)` plus the 8.6
  case that will exercise it once the real backend replaces the demo seam.
- **Status** is one of:
  - `covered` — an existing automated test asserts the behaviour today.
  - `manual` — no automated test; a concrete 8.6 manual case verifies it.
  - `deferred` — the product surface is a demo/no-op seam; automation and real verification wait
    for 8.13 backend hardening. The owning register row and removing ticket are named.
  - `partial` — some behaviour is automated today and the remainder is manual (8.6), deferred to a seam owner, or both.
- A `none` automated cell never means "not required". Every row still names a manual case or a
  deferred owning entry. Missing mappings block sign-off.
